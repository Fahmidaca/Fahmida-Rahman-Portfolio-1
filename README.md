## Built with

- Plain HTML, CSS and JavaScript in a single `index.html` file, with no build step
- Google Fonts: Bricolage Grotesque, Newsreader, JetBrains Mono
- Canvas animation for the physiological-signal monitor in the hero
- Automatic light and dark mode based on the visitor's system setting

## Run locally

Open `index.html` in any browser.

## Deploy with GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site goes live at `https://<your-username>.github.io/<repository-name>/` within a minute or two.
